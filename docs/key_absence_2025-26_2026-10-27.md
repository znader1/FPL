## Caveats

- Absence is inferred: a key player with no row (or zero minutes) for a fixture his team played.
- A key player who started counts as present even if substituted early.
- Transferred players are bounded to their first appearance for the club; the window closes when they later play for another club or the bootstrap marks them unavailable with 'joined' / 'loan' news.
- Per-team n is small; read the shrunk column (toward the league pool, k=4) before the raw one.
- Teammates-only ratio = whole-team effect / (1 - key share) when the replacement absorbs the share, so it is inflated for better players; the share-adjusted column removes that.
- Expected xG controls for opponent defence and venue via the production ratings path (no carryover seed for 2025-26: live-only, no shrinkage).
- 2025-26 selection uses season totals from the same matches (identical for every player, noted).
